# Contributing

Thank you for your interest in contributing to 365 Tao: Daily Meditations. Contributions — whether additions, edits, formatting improvements, or fixes — are welcome and appreciated.

By contributing to this repository, you agree that your contributions will be licensed under the GNU General Public License v3.0 or later (GPL-3.0-or-later), and you warrant that you have the right to grant this license for any content you submit.

## How to contribute

1. Fork the repository to your GitHub account.
2. Create a descriptive branch (e.g., `add/day-032`, `fix/typo-day-010`, `formatting/day-100`).
3. Make your changes in the `meditations/` directory (or other appropriate paths). Keep files as plain Markdown (`.md`) where possible.
4. Commit your changes with clear messages and push the branch to your fork.
5. Open a pull request against this repository's `main` branch and include a short description of your change.

## Guidelines

- Keep meditations concise and respectful of Taoist inspiration.
- If you include quoted or attributed material, add a citation and ensure the source permits reuse under GPL-compatible terms.
- Use consistent file naming for daily meditations, e.g. `day-001.md`, `day-032.md`.
- For non-text assets (images, audio), add them under `assets/` and make sure you have the rights to publish them under GPL-3.0-or-later.

## Review process

Pull requests will be reviewed by the repository maintainer(s). Reviewers may request changes before merging. Small edits (typos, formatting) may be merged quickly.

## Need help?

If you're unsure where to start or want feedback on an idea, open an issue describing what you'd like to contribute and we can discuss it before you create a pull request.

Thank you for helping improve this collection.
