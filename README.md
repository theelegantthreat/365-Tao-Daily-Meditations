# 365 Tao: Daily Meditations

[![License: GPL v3](https://img.shields.io/badge/License-GPLv3-blue.svg)](https://www.gnu.org/licenses/gpl-3.0.en.html)

A daily collection of short meditations inspired by the Tao Te Ching and Taoist philosophy—one for each day of the year. This repository stores meditations, reflections, and small exercises intended for personal contemplation and mindful living.

## About

The goal of this project is to provide gentle, bite-sized meditations rooted in Taoist thought that can be read daily. Each meditation is short and self-contained so it can be used in journaling, mindfulness practice, or as prompts for discussion.

## Contents

- meditations/ - daily meditation files (one per day, e.g. `day-001.md`)
- scripts/ - helper scripts for building or formatting content
- assets/ - images or media used by the meditations (if any)

If your copy of the repository has a different structure, treat the above as a suggested layout.

## Usage

- Read one meditation each day.
- Use the meditations as journaling prompts or short readings in a mindfulness or study group.
- The files are plain Markdown for easy reading and portability.

Example:

```bash
# view day 1 meditation in the terminal
less meditations/day-001.md
```

## Contributing

Contributions are welcome. A few guidelines:

1. Fork the repository and create a branch for your changes.
2. Add or edit meditation files in the `meditations/` directory. Prefer plain Markdown files named consistently (e.g. `day-001.md`).
3. Keep meditations concise and respectful of Taoist inspiration—cite any direct quotes or sources.
4. Open a pull request with a short description of your change.

If you want help getting started, open an issue describing what you want to add or change.
