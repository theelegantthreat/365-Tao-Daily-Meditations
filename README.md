# 365 Tao — Daily Meditations

[![License: GPL-3.0-or-later](https://img.shields.io/badge/License-GPL--3.0--or--later-blue.svg)](https://www.gnu.org/licenses/gpl-3.0.txt)

Android app that provides short daily meditations and inspiration for Tao enthusiasts.

## Overview

This repository contains the Android application source for "365 Tao — Daily Meditations". The app is written in Kotlin and delivers a daily Tao-inspired meditation or reflection to the user.

## Languages

- Kotlin — 109,873 bytes (primary language)

## Getting started

Requirements
- Android Studio (2021.1 / Arctic Fox or newer recommended)
- JDK 11 or newer
- Android SDK (API levels required by the project configured in the Gradle files)

Build and run
1. Clone the repository:

   git clone https://github.com/theelegantthreat/365-Tao-Daily-Meditations.git
2. Open the project in Android Studio.
3. Let Gradle sync and install any SDK components Android Studio prompts for.
4. Build and run on an emulator or connected device.

Command-line (Gradle)
- ./gradlew build
- ./gradlew assembleDebug
- ./gradlew test

## Project structure

The app is implemented using Kotlin. Standard Android project structure is used (app module, resources, manifest, Gradle build files).
